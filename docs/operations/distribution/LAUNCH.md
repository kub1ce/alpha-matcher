# Alpha Matcher - локальный запуск

Для запуска нужна Java 25. Откройте PowerShell в папке поставки и проверьте версию Java:

```powershell
java -version
```

Запустите приложение:

```powershell
java -jar .\alpha-matcher.jar --spring.profiles.active=demo --server.address=127.0.0.1 --server.port=8080
```

В браузере откройте `http://127.0.0.1:8080/login`. Выберите роль и нажмите «Войти» с предложенными значениями. В локальной демонстрации используются встроенные примеры, изменения сбрасываются при перезапуске. Отдельная база данных не нужна. Вход демонстрационный. Используйте приложение только локально со встроенными примерами. Реальные банковские данные использовать нельзя.

Если порт 8080 занят, укажите другой свободный порт в команде и адресе браузера. Для остановки нажмите Ctrl+C в окне запуска. Для повторного запуска выполните ту же команду.
