# Сущности базы данных

## 1. Клиент (`client`)

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `inn` | `VARCHAR(12)` | да | ИНН, если применим и доступен |
| `name` | `VARCHAR(512)` | нет | Наименование или Ф. И. О. в доступном источнике |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |
| `updated_at` | `DATETIME(6)` | нет | Время последнего изменения записи |

## 2. Договор (`contract`)

Договор, с которым система может сопоставить операцию

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `client_id` | `BIGINT UNSIGNED` | нет | Ссылка на клиента, с которым связан договор |
| `contract_number` | `VARCHAR(128)` | нет | Номер договора |
| `contract_date` | `DATE` | да | Дата заключения договора |
| `status_id` | `SMALLINT UNSIGNED` | нет | Ссылка на статус договора |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |
| `updated_at` | `DATETIME(6)` | нет | Время последнего изменения записи |

## 3. Операция (`operation`)

Банковская операция, которая поступает в систему и может участвовать в сопоставлении

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `client_id` | `BIGINT UNSIGNED` | да | Клиент, к которому система относит отслеживаемую операцию |
| `operation_type_id` | `SMALLINT UNSIGNED` | нет | Ссылка на тип операции |
| `operation_at` | `DATETIME(6)` | нет | Дата и время операции |
| `amount` | `DECIMAL(19,4)` | нет | Сумма операции |
| `currency_code` | `CHAR(3)` | нет | Код валюты |
| `payment_purpose` | `TEXT` | да | Назначение платежа, если доступно |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |
| `updated_at` | `DATETIME(6)` | нет | Время последнего изменения записи |

## 4. Участник операции (`operation_party`)

Хранит сведения об участниках конкретной операции отдельно от самой операции. Описывает плательщика, получателя и иные роли, в том числе случаи платежа за 3е лицо

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `operation_id` | `BIGINT UNSIGNED` | нет | Ссылка на операцию |
| `role_id` | `SMALLINT UNSIGNED` | нет | Роль участника в операции |
| `sequence_no` | `SMALLINT UNSIGNED` | нет | Порядковый номер участника в рамках роли |
| `client_id` | `BIGINT UNSIGNED` | да | Ссылка на известного клиента, если он установлен |
| `name` | `VARCHAR(512)` | да | Имя или наименование из доступных сведений |
| `inn` | `VARCHAR(12)` | да | ИНН участника, если доступен |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |

## 5. Кандидат/результат сопоставления (`operation_contract_match`)

Связывает операцию и договор, хранит состояние и основание сопоставления. В черновике таблица может представлять как предложенного кандидата, так и подтверждённую связь

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `operation_id` | `BIGINT UNSIGNED` | нет | Ссылка на операцию |
| `contract_id` | `BIGINT UNSIGNED` | нет | Ссылка на договор-кандидат |
| `status_id` | `SMALLINT UNSIGNED` | нет | Ссылка на статус сопоставления |
| `method_id` | `SMALLINT UNSIGNED` | нет | Ссылка на способ сопоставления |
| `reason` | `TEXT` | да | Краткое объяснение/основание сопоставления |
| `decided_at` | `DATETIME(6)` | да | Время принятия решения, если оно было |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |
| `updated_at` | `DATETIME(6)` | нет | Время последнего изменения записи |

> *Несколько кандидатов для одной операции допустимы?*

## 6. Справочники

| Таблица | Назначение |
| --- | --- |
| `contract_status` | Статусы договоров |
| `operation_type` | Типы операций |
| `currency` | Коды валют |
| `operation_party_role` | Роли участников операции |
| `match_status` | Статусы сопоставления |
| `match_method` | Способы сопоставления |
