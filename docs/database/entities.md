# Сущности базы данных

## 1. Клиент (`client`)

Клиент банка или участник договорных отношений, сведения о котором доступны системе

Одна сущность используется для физических лиц, индивидуальных предпринимателей и юридических лиц. Тип определяется через `client_type`.

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `bank_client_id` | `VARCHAR(64)` | да | Идентификатор клиента в банковской информационной системе |
| `client_type_id` | `SMALLINT UNSIGNED` | нет | Тип клиента: ФЛ, ИП или ЮЛ |
| `inn` | `VARCHAR(12)` | да | ИНН, если применим и доступен |
| `last_name` | `VARCHAR(128)` | да | Фамилия физического лица |
| `first_name` | `VARCHAR(128)` | да | Имя физического лица |
| `middle_name` | `VARCHAR(128)` | да | Отчество физического лица |
| `birth_date` | `DATE` | да | Дата рождения |
| `birth_place` | `VARCHAR(512)` | да | Место рождения |
| `citizenship` | `VARCHAR(128)` | да | Гражданство |
| `document_type_id` | `SMALLINT UNSIGNED` | да | Вид документа, удостоверяющего личность |
| `document_series` | `VARCHAR(32)` | да | Серия документа |
| `document_number` | `VARCHAR(32)` | да | Номер документа |
| `document_issue_date` | `DATE` | да | Дата выдачи документа |
| `document_issued_by` | `VARCHAR(512)` | да | Кем выдан документ |
| `document_department_code` | `VARCHAR(16)` | да | Код подразделения |
| `registration_address` | `TEXT` | да | Адрес регистрации |
| `is_in_terrorist_extremist_list` | `BOOLEAN` | нет | Текущий результат проверки по перечню экстремистов и террористов |
| `is_bank_client` | `BOOLEAN` | нет | Признак того, является ли лицо клиентом банка |
| `pin` | `CHAR(6)` | да | ПИН клиента, если доступен |
| `name` | `VARCHAR(512)` | да | Наименование организации или иное наименование из источника |
| `legal_form_id` | `SMALLINT UNSIGNED` | да | Организационно-правовая форма |
| `ogrn` | `VARCHAR(15)` | да | ОГРН/ОГРНИП |
| `ogrn_date` | `DATE` | да | Дата регистрации ОГРН/ОГРНИП |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |
| `updated_at` | `DATETIME(6)` | нет | Время последнего изменения записи |

### 1.2 Тип клиента (`client_type`)

Справочник типов клиентов.

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `SMALLINT UNSIGNED` | нет | Внутренний первичный ключ |
| `code` | `VARCHAR(32)` | нет | Уникальный технический код |
| `name` | `VARCHAR(128)` | нет | Отображаемое название |
| `is_active` | `BOOLEAN` | нет | Признак активности |

На данные момент используются:

- `INDIVIDUAL` — физическое лицо;
- `ENTREPRENEUR` — индивидуальный предприниматель;
- `LEGAL_ENTITY` — юридическое лицо.

## 2. Договор (`contract`)

Договор не содержит прямого `client_id`, поскольку у него несколько участников. Связи с клиентами представлены через `contract_party`.

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `contract_type_id` | `SMALLINT UNSIGNED` | нет | Тип договора |
| `contract_number` | `VARCHAR(128)` | нет | Номер договора |
| `contract_date` | `DATE` | да | Дата договора, предварительно оставлена для алгоритмов, использующих даты |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |
| `updated_at` | `DATETIME(6)` | нет | Время последнего изменения записи |

## 3. Сторона договора (`contract_party`)

Представляет сторону конкретного договора.

Предусмотрены три роли:

- плательщик;
- получатель;
- выгодоприобретатель.

Если сторона является известным клиентом банка, используется `client_id`.

Если сторона не сопоставлена с клиентом банка, могут быть сохранены доступные исходные данные `name` и `inn`.

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `contract_id` | `BIGINT UNSIGNED` | нет | Ссылка на договор |
| `role_id` | `SMALLINT UNSIGNED` | нет | Роль стороны договора |
| `client_id` | `BIGINT UNSIGNED` | да | Ссылка на клиента банка, если сторона идентифицирована |
| `name` | `VARCHAR(512)` | да | Наименование/Ф. И. О. стороны из доступного источника |
| `inn` | `VARCHAR(12)` | да | ИНН стороны, если доступен |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |

Для одного договора предполагается одна сторона каждой из предусмотренных ролей.

## 4. Операция (`operation`)

Банковская операция, поступающая в систему.

Операция имеет двух участников: плательщика и получателя.

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `reference` | `VARCHAR(128)` | нет | Уникальный референс проводки / уникальный ключ операции |
| `operation_at` | `DATETIME(6)` | нет | Дата и время операции |
<!-- | `currency_code` | `CHAR(3)` | нет | Код валюты |
| `amount` | `DECIMAL(19,4)` | нет | Сумма операции в исходной валюте | -->
| `amount_rub` | `DECIMAL(19,4)` | да | Сумма операции в рублях |
| `payment_purpose` | `TEXT` | да | Назначение платежа |
| `status_id` | `SMALLINT UNSIGNED` | нет | Статус операции |
| `contract_id` | `BIGINT UNSIGNED` | да | Привязанный договор; `NULL`, если договор ещё не определён |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |
| `updated_at` | `DATETIME(6)` | нет | Время последнего изменения записи |

### 4.1 Участник операции (`operation_party`)

Представляет одну сторону банковской операции.

Предусмотрены две роли:

- плательщик;
- получатель.

Сведения об участнике вынесены в отдельную таблицу, поскольку в одной операции необходимо хранить отдельный набор атрибутов отправителя и получателя.

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `operation_id` | `BIGINT UNSIGNED` | нет | Ссылка на операцию |
| `role_id` | `SMALLINT UNSIGNED` | нет | Роль участника в операции |
| `client_id` | `BIGINT UNSIGNED` | да | Ссылка на известного клиента банка |
| `client_type_id` | `SMALLINT UNSIGNED` | нет | Определённый тип участника: ФЛ, ИП или ЮЛ |
| `pin` | `CHAR(6)` | да | ПИН участника, если доступен |
| `branch_code` | `CHAR(4)` | да | Код отделения отправителя/получателя |
| `inn` | `VARCHAR(12)` | да | ИНН участника |
| `account_number` | `VARCHAR(64)` | да | Номер счёта участника |
| `name` | `VARCHAR(512)` | да | Имя/наименование участника |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |

## 5. Кандидат сопоставления (`operation_contract_candidate`)

Техническая таблица для временного хранения результатов предварительного поиска договоров-кандидатов.

Не является постоянной бизнес-сущностью.

| Поле | Тип | NULL | Назначение |
| --- | --- | ---: | --- |
| `id` | `BIGINT UNSIGNED` | нет | Внутренний первичный ключ |
| `operation_id` | `BIGINT UNSIGNED` | нет | Ссылка на операцию |
| `contract_id` | `BIGINT UNSIGNED` | нет | Ссылка на договор-кандидат |
| `reason` | `TEXT` | да | Краткое основание попадания договора в кандидаты |
| `created_at` | `DATETIME(6)` | нет | Время создания записи |

## 6. Статус операции (operation_status)

Жизненный статус операции в системе.

| Код | Значение |
| --- | --- |
| `LOADED` | Загружена |
| `REJECTED` | Отклонена |
| `PROCESSED` | Обработана |

## 7. Роли участников операции (operation_party_role)

| Код | Значение |
| --- | --- |
| `PAYER` | Плательщик |
| `RECIPIENT` | Получатель |

## 8. Роли сторон договора (contract_party_role)

| Код | Значение |
| --- | --- |
| `PAYER` | Плательщик |
| `RECIPIENT` | Получатель |
| `BENEFICIARY` | Выгодоприобретатель |
